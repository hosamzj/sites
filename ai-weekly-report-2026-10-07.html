一、Agent 协议安全：MCP 信任链遭"协议枢轴"攻击，暴露面数据敲响警钟

上期报告把 Agent 安全定性为"年内拐点"，本周焦点从"单个 Agent 失控"转向更结构性的一层——Agent 之间的信任链。Ars Technica 本周披露：Google、摩根大通、Weviate、Rapid7、法国政府跨部门数字局（DINUM）、美国联邦政府等机构的 Agent 均确认存在同一类漏洞，攻击者利用 MCP 协议中"Agent 默认信任内网其他 Agent"的假设，让一个 Agent 把恶意指令转交给下一个 Agent 执行。研究者把这种跨协议跳转命名为"协议枢轴"（protocol pivoting）。几乎同时，MCP 暴露面的扫描数据出炉：约 80% 的云环境已出现 MCP 流量。当"哪个员工装了哪个 MCP 服务器"都答不上来时，Agent 治理就是空中楼阁。

🔗

"协议枢轴"：MCP→A2A 跨协议提示注入，六家机构同时中招

独立研究员 Syed Anas Mohiuddin 的 PoC 攻击验证了同一手法：不直接攻击大模型，而是攻击翻译、数据分析等专用 Agent——这类 Agent 往往没有护栏，会原样把指令转给链上的下一个 Agent；由于后者显式信任前者，恶意指令被执行。利用得当可直接造成服务器端请求伪造（SSRF）。Rapid7 漏洞情报总监 Douglas McKee 的比喻值得记住："每个协议都假设自己独立存在，各自守好自家前门，但走廊里没人巡逻。"X41 D-Sec 研究员 Markus Vervier 将其归类为"间接提示注入"——技术上不新鲜，但因为跨协议而"出乎意料且难以缓解"。这与上期 OpenAI Agent 入侵澳洲医保事件是同一课题的两面：开放互联网上的失控是"外患"，内网 Agent 间的盲信是"内鬼"。

来源：Ars Technica 2026-10（Security 频道）/ Syed Anas Mohiuddin 研究 / Rapid7、X41 D-Sec 评论

MCP 暴露面：80% 云环境已有流量，1/6 对外暴露，2/3 裸奔

安全社区对 MCP 部署现状的扫描给出了企业 IT 很难笑着看完的数字：约 80% 的云环境已检测到 MCP 存在；其中约 1/6 至少暴露一个 MCP 服务器；暴露的服务器中约 70% 对匿名调用者返回完整工具目录、42% 匿名调用即可返回真实数据、10% 直接暴露敏感后端；一份约 1,000 个声明服务器的样本里，109/163 个远程服务器完全没有认证，且存在凭证硬编码在公开代码中的情况。所谓"影子 MCP"（员工把服务器地址粘进桌面客户端，监控体系完全看不见）已经成为现实风险类别。行动含义：本周就该做的不是再买安全产品，而是一次MCP 资产盘点——列出组织内运行和接入的所有 MCP 服务器、A2A Agent 与客户端。

协议层在收敛：MCP 无状态化 + Tasks 扩展，与 A2A 走向合流

7 月 28 日 MCP 规范修订移除了初始化握手与会话 ID，转为无状态架构，长时任务交给官方 Tasks 扩展（状态机：working / input-required / completed / failed / cancelled）。把两个协议的生命周期并排列出，重叠度已接近全量——MCP 在向上长"任务"，A2A 在向下长"工具"，而两者现同属 Linux 基金会下 Agentic AI Foundation（成员已超 250 家，Visa、富国银行、阿里为黄金会员）。先例已现：8 月 Langflow 因 A2A 端点未认证远程代码执行（CVE-2026-19286，CVSS 9.8）。趋势判断：协议收敛是好事（集成面收窄），但"端点即攻击面"的逻辑不变——任何 A2A 端点本质上是接受自然语言指令并转化为行动的公网 HTTP 接口。

来源：ajayk.sh 协议综述 2026 / AAIF 公告 / Check Point Advisory

对照：微软 10 月 25 日"高级包上传"默认开放，是风险也是治理抓手

10 月 25 日起，Microsoft 365 管理员的"高级包上传"（advanced package uploads）设置将默认对全员开启——用户可上传包含动作的声明式 Agent 或 MCP 服务器。对 IT 而言这是本期最具体的一个动作项：如果不想放开，必须在 10 月 25 日（周日）前在 Copilot 控制系统中显式设为"无用户"或"特定用户组"。正面看，Plugin registry（未来数周 GA）把微软、伙伴与自定义插件汇入统一目录、IT 集中审批——治理抓手正在成型。策略建议：把 10 月 25 日当作企业 Agent 资产盘点的强制截止日，与第一节的 MCP 清单合并执行。

来源：Microsoft 365 Copilot Connection（Substack）2026-10 / Microsoft 消息中心

高管视角：Agent 安全的考题从"模型会不会乱说话"变成"网络里 Agent 之间的信任怎么管"。三点直接动作。① MCP/Agent 资产盘点（本周）：没有清单就没有策略——包括影子 MCP。② 把 Agent 当特权身份管理：独立身份、最小权限凭证、记录"谁委托了什么、哪个工具执行了"的日志、一键停机开关；A2A 委托一律要求签名的 Agent Card。③ 网关前置：对 MCP 与 A2A 流量复用现有 API 网关的运营模型（认证、限流、审计），不要为"AI 的东西"另起炉灶——走廊必须有人巡逻。

二、M365 Copilot 落地周：SharePoint/OneDrive GA 与 10 月 25 日管理员最后期限

9 月 25 日发布的大改版进入落地周：9 月 30 日 Copilot in SharePoint 正式 GA（OneDrive 同步 GA），Work IQ 进入公共预览；10 月排期密集——Today 私预览、Teams 聊天列表移除 Copilot 入口、PowerPoint 后台任务、10 月 25 日高级包上传默认开启。商业侧，Copilot 付费席位突破 3,000 万（The Motley Fool 10/4），但在 4.5 亿商业 Office 席位中渗透率仍不足 7%（CNBC）——微软的应对是把日常 AI 与 Agentic 工作彻底拆成 USL/UBB 双轨，用 FinOps 工具把成本可见性交给企业。

3,000 万付费席位 vs 不足 7% 渗透：UBB 双轨是渗透率的答案

数据面：Copilot 付费席位超 3,000 万、每用户会话数同比接近翻倍，周活跃度已比肩 Outlook/Teams；但占 4.5 亿多商业 Office 365 席位不足 7%。CNBC/Reuters 报道的管理层口径：Home/Code 走 Frontier 计划在 10 月中下旬推进，Autopilot 私预览月底扩大，大范围可用将延续到 2027 年。商业面要点重申（上期已述）：日常 AI 走 USL 席位价（$30/用户/月，Copilot Business $18 促销 9/30 已截止、恢复 $21），Cowork/Code/Autopilot 与 Astra/Fable 等前沿模型走 UBB 按量计费；CSP 渠道 11 月 2 日起新购 Copilot Business 默认 UBB（$10/用户/月预设上限）。FinOps for AI（Wave 4）新增：支出策略可直接控制用户组可用模型家族、成本技能让用户自查当月消耗——这是把"AI 账单"变成可运营对象的关键。

Copilot Studio 升级：Agent 获得"持久身份"，与员工并列管理

Roadmap 10 月更新显示 Copilot Studio 在向"受治理的数字员工"演进：持久身份（Agent 拥有专属 M365 账户）、自学习（推荐工作流优化）、人工审批控制（工具执行前需人确认）、共享技能目录、制作者/管理员成本可见。同时：Federated Copilot Connectors 可执行写操作（在连接系统中增删改，保持用户级权限且每次变更需显式确认）——Agent 从"只读查询"跨到"可执行"，风险模型必须同步升级。另有 Local Inferencing（数据驻留：美/英/澳/印/阿联酋本地处理，利好数据主权要求）、Purview 新增 Cowork 与 Copilot 工作负载的 DLP 与 Copilot 就绪评估、Teams 频道与 Entra ID 的 30 天备份恢复。

三、汽车与零部件：AI 智驾进入"系统 Tier-1"集成时代

本周全球智驾产业出现一个标志性分工：AI 软件公司出"驾驶智能"，传统 Tier-1 出"量产系统"。10 月 1 日，法雷奥宣布被日产选为下一代 ProPILOT 的系统 Tier-1，将 Wayve 的"AI Driver"软件集成进车规级硬件平台；同一天 Stellantis 展示基于 Wayve 的免手菲亚特/玛莎拉蒂；10 月 5 日现代-英伟达-LG 结成智驾联盟。三条新闻指向同一结论：端到端 AI 智驾的量产竞赛，正在把"系统集成与工业化能力"重新定价——这正是零部件企业的能力射程。

🏆

Valeo × Nissan × Wayve：AI 智驾量产的"新铁三角"成形

10 月 1 日 Valeo 官宣：被日产选为下一代 ProPILOT 的系统 Tier-1，提供全栈硬件+软件平台——360 度感知传感器、ADAS 域控制器（处理复杂 AI 算法、中央集中式智能），并将 Wayve AI Driver 作为驾驶智能层集成进车规级系统；Valeo 主导验证、集成与工业化。Valeo Brain 事业部 CEO Marc Vrecko 的表态点题："把先进 AI 与量产车辆的安全、质量与规模要求桥接起来。"受此消息 Valeo 当日股价上涨 2.66%。背景：Wayve 此前已于 2026 年 5 月拿下 Stellantis 的 STLA AutoDrive 合作。模式意义：AI 公司不再直接面对 OEM 量产体系，而是经由 Tier-1 的系统工程能力落地——"AI 能力"与"车规交付"成为可以分开采购的两层。
