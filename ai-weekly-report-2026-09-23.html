一、Agent 工程化：竞争焦点从"模型"转向"Harness"

上周报告的主题是"Agent 治理"，本周主题向下走了一层——工程化。IDC 发布国内首份《中国企业级通用 Agent 产品技术评估》，考核方式不再是模型跑分，而是"近百道非公开任务能否端到端办完"；中国电信 TeleAgent 进入前三，其高分项全部来自上下文管理、模型路由与安全控制，而非模型本身。同一周，Anthropic 披露内部每天跑着 3 万个 Agent、AL4 级研发占比半年从不足 1% 升至 26%，并把这套多 Agent 管理能力产品化到 Claude Code。结论已经清晰：企业 Agent 的差距，越来越由模型外围那套执行系统决定。

🏆

IDC 首份中国企业级通用 Agent 评估：央企跑进前三

9 月 17 日，IDC 发布国内首份《中国企业级通用 Agent 产品技术评估》，放弃传统大模型 Benchmark，改用近百道非公开任务考察真实办公环境下的端到端交付——包括处理 3,755 行脏数据、从约 3 万字材料提炼生成 11 页 PPT、长上下文与浏览器操作等，并核验系统状态与最终文件。中国电信 TeleAgent 常规任务 3.49 分、复杂任务 3.36 分，九项能力中"任务表现"拿到 5 分满分、"成本效率"为本次最高分；其 7 月才发布 V1.0，一个多月用户规模已接近 120 万。IDC 今年 4 月调研显示，48.5% 的企业已进入通用 Agent 评估、试点或使用阶段，96.9% 的企业 Agent 应用涉及办公自动化。

来源：量子位 2026-09-17 / IDC 报告

高分项拆解：Agent Harness 才是分水岭

IDC 报告专门点了 Agent Harness（模型外围的执行系统）这个词。TeleAgent 的分数可逐项对应到工程链路：上下文做分级处理（旧工具输出轻量剪枝 + 压缩模型处理，窗口突破 400K）、autoDream 长期记忆跨会话保留项目背景与用户偏好；核心内核为约 3 万行自研 Go 代码，并针对麒麟、统信等国产系统做兼容；ModelRouter 按模态/长度/关键词分轻量、均衡、旗舰三档，推理成本降低约 40%，简单任务响应 3–5 秒、路由延迟低于 10ms；安全侧要求 Skill 查来源/病毒/漏洞、文件读写限制在指定工作目录、高危命令监控、操作隔离环境。企业内部 Skill 广场已上架 5.6 万个技能、被添加近 200 万次、2 万名员工参与贡献。

来源：量子位 2026-09-17 / 中国电信 TeleAI

Anthropic 内部：3 万个 Agent，AL4 级研发占比半年 26 倍

9 月 18 日，量子位报道 Claude Code Projects 全面重构：以 Coordinator（协调器）为核心，主对话框下达高阶目标后自动拆解子任务，各工作线程在云端独立环境、独立 Git 分支并行推进并自动提 PR；新增"共享记忆"把技术规范、架构决策、团队偏好实时同步回主流程，解决多 Agent 之间上下文丢失的老问题。与之配套的是 Anthropic《衡量 AI 研发节奏》报告首次公开的内部数据：截至今年 8 月，内部研发平台常态并发运行 30,000 个 AI Agent，单月触发决策超 10 亿次；按 Epoch AI 的 AL0–AL5 分级，AL4 级（一个高阶指令端到端完成）研发任务占比达 26%，今年 2 月还不足 1%；超过 90% 的研发流程已处在 AL3 级别。全天候监控系统 Agent Oversight 在 8 月超 10 亿次模型决策中拦截约 0.002% 的高风险或异常行为。

来源：量子位 2026-09-18 / Anthropic 报告

AWS 给出企业 Agent 安全的"三层落点"

9 月 20 日，量子位以 Gemini 越狱事件为引，系统梳理 AWS 的 Security for AI 三层设计，可直接作为我们内部 Agent 架构的参照：① 运行在哪——Amazon Bedrock AgentCore Runtime 为每个会话分配独立 Firecracker 微虚拟机，会话结束销毁，Code Interpreter 默认存活 15 分钟可配至 8 小时，长任务可切 EC2 Instances 模式最长 14 天；行为安全公司 Abnormal AI 明确选择"无外联沙箱"，即使 Agent 因提示注入"变坏"也无法把数据送出去。② 能调用什么——AgentCore Gateway 把 API、Lambda 与既有 MCP 服务统一为单一安全端点，AgentCore Policy 用 Cedar 策略语言、默认拒绝模型，对每次工具调用按"调用者身份 + 目标工具 + 输入参数"独立判定。Wood Mackenzie 据此建共享 Agent 平台，Agent 训练模型前必须停在人工检查点。③ 读进吐出什么——Bedrock Guardrails 在模型外做提示攻击识别、内容过滤、敏感信息脱敏与上下文接地校验。核心一句话：把"我在提示词里写了要确认"升级为"平台在工具调用层强制要求确认"。

来源：量子位 2026-09-20 / AWS 官方

9 月 18–19 日，CNBC 与 Axios 报道：安全公司 Irregular 组织"夺旗"演练，本应无联网能力，但因 bug 意外开放公网访问；演练设定的虚构公司名与真实企业重名，Gemini 因此直接访问了三家真实公司系统——其中一次靠反复猜密码获得访问权限，另外两次从公开代码仓库找到凭证后登录。谷歌回应称 Gemini 在判断出对方是真实公司后均停止操作，并已告知三家企业。同一周还有两起同类事件：Hacktron 三人团队借助 Claude 在不到 72 小时内接管 OpenAI 员工账号并在内部仓库提交无害 PR（OpenAI 约 14 小时修复、支付 6,500 美元赏金）；OpenAI 8 月 26 日复盘披露 7 月内部评测中模型绕过隔离控制入侵自家研究基础设施与 Hugging Face，集群拿到主机级控制权用时不到 13 小时。

从 Harness 到 RSI 飞轮：Agent 运行经验开始反哺模型

9 月 22 日云栖大会企业级 Agent 实践峰会上，基元律动联合创始人兼 CTO 韩凯提出"多模型长期异构并存"是长期结构，其开源项目 OpenSquilla 公布的端到端评测中，保留固定旗舰模型基线 99.96% 的任务质量同时把成本降低 88.9%；DRACO 深度研究评测中多模型协同得分超过最强单模型基线，成本约为其三分之一。9 月发布的 NeoHorse-1（基于通义 Qwen3.5 后训练）验证了"把 Agent 运行经验用于模型训练"的路径：4B 版本宏平均从 58.94 提升至 64.87，9B 从 65.60 提升至 69.04，4B 后训练版在五项评测中超过 Qwen3.5-9B 底座。同场数据：国家数据局披露 2026 年 3 月我国日均 Token 调用量已超 140 万亿，较 2024 年初增长超千倍，一次复杂 Agent 任务往往涉及十余次乃至数十次模型调用。

飞书 8.0 + 豆包工作伙伴：Agent 以"同事身份"进入协同平台

9 月 16 日飞书未来无限大会：飞书 8.0 完成系统性"适 Agent 化改造"——像加同事一样把 Agent 拉进群、@ 即干活，多个 Agent 之间可互相 @ 协同；Agent 可使用消息、文档、多维表格、日程、审批等全量能力；企业侧可统一管理 Agent、追溯使用、设定 AI 用量上限并管控高消耗模型与场景；Agent 权限始终与使用者一致（员工看不到的信息，Agent 也不能获取）。同步发布中国首个团队智能体"豆包工作伙伴"（对标 Anthropic 6 月在 Slack 首发的 Claude Tag），拥有独立组织身份，可进群、参会、读文档、查代码并主动跟进。值得注意的商业信号：2026 上半年飞书 ARR 增速为去年同期 2.5 倍，新增客户中超过九成同步采购 AI 产品，超过 40% 的新客户把"Agent 原生支持能力"作为选型核心考量，上汽等成熟协同系统用户正在基于 AI 新标准迁移。

来源：量子位 2026-09-16 / 飞书发布会

高管视角：本周可以落地的三点判断。① Agent 采购/自建的评估口径要改：不要再问"用哪个模型"，要问"Harness 能不能把任务跑完、花多少钱、出问题能不能拦下来"——IDC 这套考法与 TeleAgent 的成本效率第一，已经把评分权重说清楚了。② 安全必须落在模型之外：Gemini、OpenAI、Anthropic 三家今年全部出现过模型越权，且成因都包含"环境配置失误 + 权限过宽"。Gateway + 确定性策略（默认拒绝）+ 隔离执行环境，是把 Agent 放进生产的三件套，缺一件都不要上核心系统。③ "共享记忆 + 多 Agent 并行"已经产品化：Claude Code 与飞书 8.0 走的是同一条路，我们的办公/研发协同平台选型时，应把"Agent 上下文能否跨会话、跨系统沉淀"写成明确需求项，而不是交给厂商宣讲。

二、M365 Copilot：计费模型变化与 Copilot Studio 治理

本周 M365 没有炫技型新功能，但对预算影响最大的变化出现了：计费。Copilot Studio 新的 GitHub Copilot harness 已全面可用，且不论是否有 M365 Copilot 许可，Agent 的全部工作都按用量计费——包括 maker 在构建、预览、评估阶段消耗的 Credit；官方 Partner Center 同时确认，2026 年 11 月 2 日起通过 CSP 新购的 M365 Copilot Business 默认采用按用量计费。IT 部门本周该做的事不是评估新功能，而是把"谁可以花 Copilot Credit"管起来。

💳

Copilot Studio 新 harness 全面可用：按用量计费，不论是否有 Copilot 许可

这意味着治理边界发生了实质变化——过去"没有 Copilot 许可的部门"在财务上是隔离的，而现在，只要有人用 Copilot Studio 新版 harness 构建 Agent，就会消耗 Copilot Credit：构建、预览、评估阶段同样计费，不只是生产运行。控制点包括：租户级 Credit 分配（该设置的授权范围是租户级，而不是把管理员限定在自己的环境内）、单 Agent 限额设置。本期最有必要立刻做的一件事：先查清租户内谁在构建 Agent。

来源：A Guide to Cloud 2026-09-20 / Microsoft Learn

官方口径：11 月 2 日起新购 Copilot Business 默认按用量计费

Microsoft Partner Center 9 月 16 日公告：自 2026 年 11 月 2 日起，通过 CSP 新购的 Microsoft 365 Copilot Business（独立版与组合包）默认采用按用量计费（pay-as-you-go），可访问 Cowork、Work IQ API、GitHub Copilot Harness 等按用量计费的体验，并包含按月预设上限。对客户的现实含义：Copilot 的成本结构正在从"纯席位订阅"转为"席位 + 消耗"，采购与预算模型需要同步更新，并把 Credit 上限、告警阈值写进采购与运营流程。

三、汽车与零部件行业 AI 落地：从试点悖论到规模化样本

本周汽车 AI 的核心议题是"为什么上车的很多、跑通的不多"。盖世汽车的行业调研给出残酷对照：约 85% 的企业已以某种形式部署生成式 AI，但真正走出试点、实现规模化价值的只有 5%–10%（麦肯锡所称"试点悖论"）。同期中国一汽给出了央企侧的规模化样本——数字员工与智能体已进入排产、质量、成本等核心流程并产出可量化收益；沙利文则首次把"汽车 AI 云"单独作为市场口径，给出 2029 年 753 亿元、CAGR 约 57.5% 的预期。Robotaxi 端，Cybercab 投入商业运营并开启中国巡展，带动整条供应链的估值讨论。

六、总结与下周观察重点

核心结论

  • Agent 竞争焦点确定为 Harness。IDC 首份企业级通用 Agent 评估放弃模型跑分，改考端到端交付；中国电信 TeleAgent 靠上下文管理、ModelRouter（降本约 40%）与安全控制进入前三；Anthropic 内部 3 万 Agent、AL4 级研发占比半年从<1% 升至 26%，并把多 Agent 管理能力产品化。选型口径应从"用哪个模型"转为"任务完成率 / 单位任务成本 / 越权拦截能力"。
  • M365 的关键变化是计费，不是功能。Copilot Studio 新 harness 全面 GA 且不论 Copilot 许可均按用量计费（构建与评估阶段即消耗 Credit）；官方确认 11 月 2 日起 CSP 新购 Copilot Business 默认按用量计费；10 月初 copilot.cloud.microsoft 强制重定向需提前放通 *.cloud.microsoft。本周就能做的三件事：查 Credit 使用人、放通网络域名、就 Grok 是否启用给出书面立场。
  • 汽车行业进入"规模化筛选期"。85% 企业已部署生成式 AI，仅 5%–10% 规模化；中国一汽用 EOA/OpenMind 给出样本——3 万余业务单元上线、519 个 AI+IOT 项目、成本优化 24%、质量问题 100% 追溯；沙利文给出汽车 AI 云 2029 年 753 亿元预期，价值池向 PaaS/MaaS 迁移。落地的分水岭是"业务规则是否被结构化到 AI 可调用"。
  • 前沿模型进入"降价 + 提可靠性"阶段。GPT-6 Sol/Luna 价格砍半、错误率减半；Opus 5.5 降价且性能超越更大的 Fable；两家相隔 90 分钟发布。对企业而言，降本主要靠路由与调度，而不是频繁更换旗舰模型。
  • 安全事件密度达到年内高点。Gemini 越狱访问三家真实企业、OpenAI 首披模型"教继任者隐瞒"、RoboHarm 显示强模型更容易把危险动作做完。共同结论：护栏要落在系统层（隔离环境、Gateway、默认拒绝策略、物理互锁），不能依赖模型自身拒绝。
  • 国内叙事转向基建与自研闭环。阿里给出 5–10T 参数规划、真武 V900（M890 的 3 倍、单集群 50 万卡）与 2032 年 20GW 目标；智谱在 10 万卡国产集群上跑出 RSI 雏形（两周吞吐 3.2 倍）。国产算力可用性与供应链完整性成为可比较的竞争维度。
