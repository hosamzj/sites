一、AI 智能体生态：国产 Flash 双雄把 Agent 性价比推上新临界，开源智能体操作系统补齐工程底座

本周智能体赛道的主线是"成本曲线"：DeepSeek 与 MiniMax 两款国产 Flash 模型先后刷新 Agent 任务的性能/价格比，把"旗舰模型才能干复杂活"的默认假设打得粉碎；同时，清华开源的 PilotDeck 2.0 从工程侧回答了一个更朴素的问题——当一家企业要同时跑几十个 Agent 时，记忆怎么管、成本怎么降、任务怎么在后台持续跑。对正在评估智能体落地的 IT 负责人，这一周的信息量足够更新一次 POC 方案。

⚡

DeepSeek V4.1-Flash-1017：官方定义"性能—费用的帕累托改进"，顺手发布自研搜索 API

10 月 17 日 DeepSeek 发布 V4.1-Flash-1017（10/15 曾发生全球性宕机，两天后新模型即上架，官方并做了补偿）。与上一版 V4.1 Flash 相比，新模型在代码、Agent 任务等基准上"整齐抬头"，同时任务运行时间和输出长度被一起压下来——官方称之为"性能—费用的帕累托改进"：以前想让 Agent 干活更好，得接受它多想、多跑、多吐 Token；现在模型开始"少绕路、少说废话"。DeepSWE 测试中，该模型已在 DeepSeek Harness、腾讯 CodeBuddy / WorkBuddy 等框架下把性能-成本边界继续外推，Harness 需升级至 0.2.1-rc.1 以上才能吃满。配套动作：自研搜索引擎开放 Search / Fetch 两个 API——Search 支持限定网站、语言、发布时间，Fetch 把网页抓取成 Markdown 交给模型，每千次成功请求 5 元、失败不收费，11 月 1 日前限时免费，可直接在 Harness、Claude Code、Codex 中调用。动作建议：Agent 的"联网检索"环节从自拼方案转向评估此类托管搜索 API，注意 11/1 免费期后的成本重估。

来源：量子位 2026-10-17（DeepSeek 官方发布转述）

MiniMax M3.1 Flash：ALE 29.6% 拿下"国模 Agent 第一"，与 DeepSeek 形成互补路由

国庆期间以匿名模型"Space Bunny（玉兔）"在 OpenRouter 屠榜的 MiniMax 新模型正式揭面——M3.1 Flash（10/20 报道）。关键数据：Agents' Last Exam (ALE) 29.6% 斩获国模第一；DeepSWE v1.1 达 73.7%，反超 GPT-6.1 Sol、Claude Opus 5、Claude Fable 5，仅次于 DeepSeek V4.1-Flash-1017 的 77 分；网络安全基准 CyberGym 82.2 与 GLM-5.3、GPT-5.6 Sol 同处全球第一梯队；金融工具链 BankerToolBench 76.2 与 Claude Opus 5 并列第一；Zapier 开源的 AutomationBench-AA（横跨销售、营销、客服、财务、HR 的工作流自动化）中，单任务成本不到 0.05 美元。推理速度最快 200+ TPS（P50 维持 170+），串四个子 Agent"从等红绿灯到无感刷新"。社区已总结出"闲时 DeepSeek（谷价）、忙时 MiniMax（峰价）"的双 Flash 路由打法——Token 成本管理正式进入"多供应商路由"时代，企业 Agent 平台选型时应把路由能力列为标配需求。

来源：量子位 2026-10-20（MiniMax M3.1 Flash 发布）

清华 PilotDeck 2.0 开源：智能体操作系统，白盒记忆 + 工作舱隔离，任务成本降 83%

清华大学 THUNLP 实验室联合面壁智能、OpenBMB 开源 PilotDeck 2.0（AGPL-3.0，支持 macOS/Linux/Windows/Docker），原生支持 MCP，直击企业多 Agent 并行的三大痛点：① 工作舱（WorkSpace）物理隔离——每个项目有专属文件系统、记忆库、技能集，多任务并行不再"记忆串台"；② 白盒记忆——记忆的生成、抽取、存储、调用全链路可见可查可改，记错了一键回滚，不用整段对话作废；③ Smart Routing 分层编排——强模型管决策、小模型干杂活，官方 7 个高难度任务横评：单体 Claude Sonnet 4.6 得分 69.1 但单次 $18.36，路由编排后（Sonnet 4.6 + MiniMax-M2.7）得分 70.6、成本仅 $3.15；社媒运营场景从 $12.58 降到 $2.83，成本砍掉约六分之五、质量反升。另有 Always-on 常驻模式：关掉聊天窗口后 Agent 仍后台推进长周期任务并产出落地文件与总结报告，Web/CLI/企业微信/飞书行为一致。这是本周对"智能体工程化"最有参考价值的一项开源进展，值得纳入内部平台的技术雷达。

来源：量子位 2026-10-17（OpenBMB 开源发布，github.com/OpenBMB/PilotDeck）

DeepSeek Harness 注册 B 站官方号："一切皆插件"的 Agent 运行平台开始面向国内推广

在 10/15 宕机事故同时，名为"DeepSeekHarness"的 B 站官方账号悄然上线。Harness 是 DeepSeek 已推出的开源 Agent 运行平台：模型负责思考，Harness 负责调工具、改文件、执行命令、把复杂任务拆给多个子 Agent，核心定位"Everything is a plugin"。结合 V4.1-Flash-1017 对该平台的专项优化与 6 元新用户赠金，DeepSeek 正把 Harness 从开发者圈层推向国内大众与企业市场。对 IT 负责人的两点提示：其一，员工个人使用 Harness/Claude Code 类 Agent 工具处理工作文件的影子 IT 风险在上升，DLP 策略需覆盖 Agent 工作目录与插件调用；其二，10/15 全球宕机（对话服务 + V4 Pro / V4.1 Flash API 全受影响，第三方平台 24 小时内 86 条报障）再次证明——关键业务流对单一模型 API 的依赖必须有降级方案。

来源：量子位 2026-10-15（DeepSeek 服务中断事故记录 + B站账号观察）

管理侧两件套：连接器规则自助编辑 + SharePoint 特殊组权限审计

连接器治理自助化：管理员现可在 M365 管理中心（Settings → Search & intelligence → Data sources）直接编辑已有连接器的查询字符串（query string）与用户身份映射规则，无需提交支持工单——权限映射漂移、过滤条件收紧等场景从"支持周期"变为"分钟级自修复"，这对合规承诺（访问治理）是直接加分项。SharePoint 权限审计：管理中心新增报表，可逐项查看授予 "Everyone" / "Everyone except external users" 特殊组的条目级权限，导出后做权限审计与未授权访问排查——与 Copilot 普及带来的"过度共享内容被 AI 检索放大"风险直接相关，建议本季度跑一次全量审计。

三、汽车与零部件：巴黎车展余温下的智能化出海与 RISC-V 车规芯片路线图

巴黎车展（10/12 开幕）的后半周报道把焦点从"中国品牌来了"转向"技术怎么落地欧洲"：比亚迪给出欧洲补能与高阶智驾的明确时间表；AIVA（赛豆）ME7 进入工信部申报，"AI 定义汽车"从口号进入量产流程。而对零部件企业更关键的是底层变化——达摩院玄铁发布了 RISC-V 车规路线图，车用计算底座可能出现第三条路线。

比亚迪：欧洲 3000 座闪充站 2027 年底建成，腾势 CNOA 2027 年落地欧洲

巴黎车展集中展示第二代刀片电池、闪充技术与"天神之眼"智驾：ATTO 8 成为登陆欧洲的首款第二代刀片电池车型；补能——2027 年底前在欧洲建成 3000 座闪充站；智驾——腾势城市领航辅助（CNOA）官宣 2027 年率先落地欧洲、搭载 Z9GT。全球化数据：截至 2026 年 9 月，比亚迪新能源车覆盖 120 多个国家和地区、全球累计销量破 1820 万辆，2026 年前九个月海外销量 133 万辆已超 2025 全年。同期比亚迪官宣成为 2026 APEC 会议官方合作伙伴——中国车企的全球化叙事从卖车进入"国际活动基建"层面。对零部件供应链的含义：欧洲本地化产能、闪充桩供应链、符合欧盟数据与智驾法规的零部件认证需求将持续放量。

工信部第 412 批新车公示中，AIVA ME7 申报图与参数公开：中大型纯电 SUV（4999×1999×1616mm、轴距 3050mm），单电机 270kW / 双电机 420kW，宁德时代三元锂，车顶激光雷达，9/28 已在巴黎完成全球首秀。AIVA 今年 6 月发布时提出"AI 定义汽车，先有 AI，再有车"的路径，全系定位 20 万元以上主流市场，外界推测 ME7 售价 20 万+。智能座舱、辅助驾驶方案与车载芯片尚未完整披露。观察点：20 万级市场已出现 800V/900V 平台 + 700km 续航 + 高阶辅助驾驶的密集供给，智能化配置正在从溢价项变成准入项，对应零部件 BOM 中智能化占比继续抬升。

达摩院玄铁：首款 ASIL-B+D 双认证 RISC-V 车规 CPU，发布自动驾驶处理器路线图

10 月 19 日 RISC-V 中国峰会（深圳），达摩院玄铁发布车规增强处理器 E908A——业界首款同时达到 ASIL-B 与 ASIL-D 标准的 RISC-V CPU IP，单点安全度量 SPFM 业内首次超过 90%，面向安全岛、域控、车载网关等实时计算场景；同时首次发布自动驾驶与具身智能产品路线图，下一代 C950A 目标性能达现有 RISC-V 车规产品的 5 倍。玄铁 C950 已在四类 Agentic AI 负载上较主流传统架构提升 10% 以上（Qwen3.8-Flash-Next 推理 43 token/s）。行业预测 RISC-V 处理器年出货增速 50%、2030 年市占约 25%。对零部件企业的意义：车用 MCU/域控的第三路线（X86/Arm 之外的 RISC-V）已从"可用"走向"可靠"并开始定路线图，中长期 BOM 成本与供应安全评估应纳入 RISC-V 选项。
