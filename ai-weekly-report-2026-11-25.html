一、AI 智能体生态：谷歌「收编」MCP 并设硬期限，企业能力层之争开打

1. 本周最大事件：Google Workspace MCP 服务器 GA，2027 年 2 月 1 日起强制执行

11 月 24 日，Google 宣布 Workspace MCP 服务器（Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat、Tasks）与官方 Workspace CLI 正式 GA，同步推出全新 Google Cloud Agent Gateway——一个协议原生的 LLM / MCP / A2A 流量网关，可校验 Agent 身份（对接 Agent Registry）、执行 IAM 策略与默认拒绝的出站规则、并用 Model Armor 做提示注入筛查。最硬的一条是：AI 智能体访问 Workspace 数据必须走 MCP 或 Workspace CLI，不再允许直接调用 REST API，2027 年 2 月 1 日起技术性强制执行；同时新的《Workspace AI Tools 附加条款》禁止 Agent 长期留存派生数据与抓取 API。（来源：Google Workspace Updates（2026-11-24）、Google Cloud 博客（2026-11-24））

对制造业 IT 的意义：这是第一个大厂为「Agent 接企业数据」设下明确死线的政策——微软与 Google 两家都在把 Agent 访问收敛到受治理的协议通道内。企业内凡是通过个人 API Key、脚本直连邮箱/网盘数据的自动化，都进入了 14 个月的倒计时；数据权限、审计与 DLP 设计需要在此之前完成改造。

2. MCP 从「连接协议」升级为「企业能力层」

Jitterbit 的两篇系列长文（11 月 2 日起连载）给出了本周被广泛引用的判断：MCP 正在从 AI 连接标准演变为企业的能力暴露层。支撑数据来自 Atlassian：其 Rovo MCP Server 在 2026 年 7 月已突破每个工作日 500 万次 MCP 工具调用，其中 44% 来自软件团队以外，近三分之一是写操作——Agent 不再只是「查」，而是在真实地改数据。Oracle 本周也宣布 Autonomous AI Database 内置托管 MCP Server 与 A2A Server，数据库工具与库内 Agent 可直接以标准协议对外暴露。（来源：Jitterbit（2026-11）、Oracle 博客（2026-11））

3. InfoWorld 续篇：MCP + A2A 撑不起规模化，四层补课进入执行期

上期引用的 InfoWorld 分析（11 月 11 日）本周持续发酵，其框架被多方引用：MCP 是 Agent 的「USB 接口」（垂直连接工具与数据），A2A 是「总承包商协议」（水平连接 Agent 与 Agent），两者之下仍需补身份管理、上下文治理、业务流程再造、AgenticOps四层。微软自己的实践也印证了这一方向：11 月 11 日微软开发者博客详细演示了如何让 Copilot Studio 标准 Agent 通过 MCP 调用 Copilot Harness Agent、并让 Harness Agent 跨环境以 A2A 互通（MCP 频道与 A2A 1.0 均处于预览）——协议互通的工程样板已经落到具体配置层面。（来源：InfoWorld（2026-11-11）、Microsoft 开发者博客（2026-11-11））

4. 治理与地缘：出口管制盯上「远程算力」

  • 美国商务部 11 月 19 日出台临时最终规则《应对先进半导体的远程访问》：将先进计算出口管制从「芯片物理流动」扩展到「海外数据中心向受限国家实体远程提供算力」，并正式撤销此前的 AI Diffusion Rule，改为按目的地与最终用途的定向管制。对在中国运营 AI 负载、依赖境外算力的企业，远程调用的合规路径需要在 2027 年 1 月 19 日意见截止前摸清。（来源：AI Governance Brief（2026-11-22））
  • 全球隐私大会（GPA，11/16–18 布鲁塞尔）通过两项 AI 决议：其一明确「现有数据保护义务同样适用于智能体系统」，并把人类监督列为关键治理要求；其二聚焦教育场景儿童数据。80 余国数据保护机构达成的非约束性共识，会成为各国后续立法的底座。
对 IT 负责人的意义：「Agent 必须走受治理通道」从微软一家的产品策略升级为两大平台的共同政策，且有了硬性死线。本周可做：① 盘点企业内部所有以脚本 / API Key 直连邮箱、网盘、文档系统的自动化，标记为 2027 年 2 月前必须改造的对象；② 借鉴 Atlassian 的写操作占比，重新评估 Agent 写权限的审批与回滚设计；③ 关注美国远程算力管制对跨境 AI 工作负载的影响，法务与架构同事一起过一遍。

二、M365 Copilot：Ignite 落地下半场——D365 in Copilot、Cowork 细节与欧盟数据边界

Ignite 2026 之后的第一周，微软把发布重点从「愿景」转向「可安装的部件」：Dynamics 365 插件 GA、Cowork 逐项补能力、欧盟客户迎来 Claude 模型开通日。以下按业务插件 / Cowork 体验 / 合规三条线梳理。

1. Dynamics 365 in Copilot：100+ 预置技能 + Activate for ERP（SAP 迁移）

  • Dynamics 365 in Copilot 正式登场：Sales 插件（GA）带来客户计划、会前准备、管道优先级、交易洞察（对照季度预测追踪进展、标记决策人缺口与风险），并可直接在 PowerPoint 中生成基于 CRM 数据的提案演示；Customer Service 插件同步 GA。销售 + 服务插件合计提供 57+ 业务技能，D365 全家桶相关技能超过 100 个。
  • 面向制造业的重点：Dynamics 365 Activate for ERP 启动私有预览，首个场景是 SAP ECC 迁移——SAP ECC 主流维护临近尾声，Activate 用 Agent 能力协助判断哪些定制、集成与流程该搬迁、简化或重做，并由实施项目团队校验。对正在评估 ERP 路线的零部件企业，这是「Agent 辅助 ERP 迁移」的第一个主流商业产品。
  • Copilot Studio 新 Harness GA：官方数据称知识质量提升 20+ 分、代码分析质量翻倍、多工具调用成功率 87%→98.9%、单任务输入 token 降 45%；12 月公共预览将加入 Agent 持久身份 + 记忆 + 触发器。

（来源：Dynamics 365 博客（2026-11-17）、Microsoft Copilot 博客（2026-11-17））

2. Cowork 与 Office：从「能干活」到「干得漂亮」

  • Office in Copilot 正式 GA：对话中直接创建并协同编辑 Word / Excel / PowerPoint，文件自动存入 OneDrive；PowerPoint 新增「引用已有模板的风格」生成新演示。
  • Copilot Cowork 新增 Planner 插件与 OneNote 支持（11 月 Cowork 更新）：Planner 任务可对话式创建与更新；OneNote 笔记本可读、可经批准后改写。自定义技能上限扩至 50 个，OneDrive / SharePoint 原生支持 Markdown（含技能文件），任务历史可搜索、应用内弹窗通知。
  • 发行说明 11/17 批次的实用小改进：Excel 中 Copilot 的修改结果可直接点击跳转到对应工作表/表格/图表；Cowork 可调用本机 Edge 浏览器完成需要登录的网页操作（影子 IT 风险与效率并存）；Vision 支持共享桌面画面与手机摄像头实时分析；Outlook 支持自然语言整理（删除/移动/分类/规则，批量操作前确认）；会议可按主题与关键词检索（覆盖近两个月转录）。
  • Copilot UX 组件以插件形式进入 Cowork（SPFx 1.24）：企业把自研交互组件（审批卡片、仪表盘、预订界面）打包为插件后，员工在普通 Copilot 对话中说出需求即自动唤起——无需先找到某个 Agent。「SPA 模式」预告：未来 SPFx 方案可接管 SharePoint 站点整个首页。

（来源：Microsoft Learn 发行说明（2026-11-17）、Cowork What's New（2026-11）、Microsoft 365 开发者博客（2026-11）、Tech Community：Office at Ignite 2026）

3. 合规线：12 月 9 日欧盟客户默认开通 Claude

微软 11 月 10 日公告：Anthropic Claude 模型在 Copilot（含 Cowork）中的处理将于 12 月上旬迁入欧盟数据边界（EU Data Boundary），12 月 9 日起对所有未做过选择的欧盟/EFTA 组织默认开启 Claude，原先「仅 Office 应用内可用」的中间选项将被移除。在欧有工厂或研发中心的集团需要提前决定：默认放行、按组灰度，还是显式关闭；同时注意 Anthropic 对前沿模型保留 30 天安全监控数据的策略与内部隐私评审的衔接。（来源：Hello Growth 月度梳理引用 Microsoft Message Center MC1546438（2026-11-10））

行动清单（本周可启动）：① 若在用 SAP ECC 规划换代，把 Dynamics 365 Activate for ERP 私有预览加入评估清单——「Agent 辅助迁移」的报价与自研 Agent 的成本可以放在同一张表上比较；② 为 Cowork 的本机 Edge 能力定政策：允许访问哪些内网系统、是否需要额外审批（它意味着 Agent 可以操作任何你已登录的网页）；③ 用 SPFx 插件把 1–2 个高频审批流（如采购申请）做成 Copilot UX 组件，这是让员工「感知到 Copilot 有用」成本最低的演示；④ 欧盟实体（如有）在 12 月 9 日前完成 Claude 开关决策。

三、汽车与零部件：世界智能制造大会——「多智能体协同」从 PPT 走进车间

1. 本周行业主舞台：2026 世界智能制造大会（11 月 19 日，南京）

由中国汽车工程学会主办的「汽车行业新一代智能制造创新与实践」专题活动上，整车厂的数字全部指向同一个结论——AI 已经进入生产系统的「经营指标层」：

  • 长安数智原生超级工厂：单车 BOM 解算从 15 分钟缩至 0.5 秒；定制订单交付周期从 28 天压缩至 12 天；订单准时交付率 100%；「1+N」数字化系统向海外复制，泰国工厂复用率超 70%。
  • 理想汽车：首车试制周期从 45 天缩短至 30 天。制造工程负责人徐勉的判断值得记住：「单点 AI 应用更像入场券，而非护城河」——下半场要回答的是 AI 能否进入系统、进入经营。
  • 小米汽车给出三条主线：业务本体建模、智能体执行、数据反哺——让业务语言和数据资产可追溯、可复用；小米的判断是主要障碍不在模型能力，而在 AI 尚未进入企业价值创造机制。

（来源：科技日报（2026-11-21））

2. 小米超级工厂入选国家领航级智能工厂：260 个模型资产 + 20+ 岗位智能体

工信部等六部门 11 月 19 日发布 2026 年度领航级智能工厂培育名单，小米汽车「AI 驱动的敏捷制造高端新能源汽车超级工厂」成为北京首家入选工厂。关键数字：已沉淀 260 个模型资产、20 多个岗位智能体，AI 从单点识别、辅助分析走向多智能体协同；订单单次排产时间大幅缩减、库存周转率从 15 次提升至 71 次、订单准时交付率保持 99% 以上；压铸后地板一次成型替代 72 零件 + 800 焊点，整车下线仅需 76 秒。这是「多智能体协同制造」目前最完整的公开样板。（来源：千龙网（2026-11-25））

3. 跨国与供应链侧：西门子 Agentic AI 直连产线，通用把自动化纳入供应商评分

  • 西门子 11 月 16 日发布工业级 Agentic AI 工作流：把书面任务（示例：人形机器人夹具）自动转化为经仿真验证、可打印的零件——AI 代理自行选择夹具类型、在 Designcenter 调整几何、运行仿真、检查机器人接口并准备构建文件，全程可追溯；将在 Formnext 2026 展示，并接入其埃朗根电子工厂的自适应生产单元。对模具、备件、小批量变体生产是直接利好。（来源：AutoPresse（2026-11））
  • 通用汽车计划到 2028 年将北美工厂自动化水平提高 20%，自研厂内零部件运输自主移动机器人（Kokomo 工厂）；更重要的是——通用已开始将自动化能力纳入供应商评估：竞标新项目的零部件企业须提交自动化计划，评分将可能影响采购合同决策。上一期丰田的机器人路线图是「传导预告」，本周通用的供应商评分机制是「传导落地」。（来源：财联社（2026-11-18））
  • 赛力斯超级工厂的人形机器人已上岗讲解与辅助检测，工厂拥有超 3000 台工业机器人、关键工序 100% 自动化；长安涂装车间首台视觉 AI 刷胶机器人上线，产线 JPH 提升约 8%，风险识别准确率超 99.5%；法雷奥与 QNX 的智能前视摄像头平台获多家在华车企定点，年内量产。

（来源：新浪财经 / 封面新闻（2026-11-19）、AMTS INSIGHT 一周要闻（2026-11））

给汽车零部件企业的启示：主机厂两条传导路径本周同时落地——丰田的资本开支路线（机器人进供应商工厂）与通用的评分路线（自动化计划影响订单）。建议：① 把「自动化与数据连通水平」当作 2027 年商务谈判资产来建设，而不仅是成本项；② 参考小米「模型资产 + 岗位智能体」的沉淀方式，盘点自家工厂可被 Agent 复用的工艺模型（检测、排产、归因）数量——这个数字未来可能成为客户审计的一部分；③ 西门子「提示词→验证→可打印零件」链路对模具/备件业务是短期可试点场景。

四、大模型格局：Gemini 4 Neon 补位、Qwen4-Max 入局与出口管制升级

1. 三天四旗舰：Gemini 4 Neon、Qwen4-Max、GPT-6.2 持续发酵

  • Gemini 4 Neon（Google，11 月 18 日）：填补 Carbon（重载）与 Hydrogen（高速）之间的空档，API 定价 $3 / $15 每百万 token，官方称单任务成本比 Carbon 低 32%；Gemini App 用户可在 Auto / Hydrogen / Neon / Carbon 四档间选择。
  • Qwen4-Max（阿里巴巴，11 月 16 日）：Qwen4 系列首个旗舰，API $1.50 / $4.50 每百万 token（约为 GPT-6.2 Astra 的五分之一），权重保持闭源，更小的 Qwen4 模型后续将开放权重——国产旗舰进入全球价格表。
  • GPT-6.2 Sol 进入 Microsoft Copilot：OpenAI 与微软的模型池互通继续加深，GPT-6.2 Astra / Sol 已可通过 ChatGPT 企业版与 API 使用。

（来源：A/GEO Research（2026-11-23）、Hello Growth（2026-11））

五、总结与下周观察重点

核心结论

  • 「Agent 必须走受治理通道」有了硬性死线。Google 宣布 2027 年 2 月 1 日起 Agent 访问 Workspace 强制走 MCP；配合微软 Agent 365 的治理体系，「协议 + 身份 + 网关」三段式架构成为两强共识，企业直连 API 的影子自动化进入倒计时。
  • Ignite 落地下半场对制造业更实。Dynamics 365 in Copilot（销售/服务 100+ 技能）、Activate for ERP 的 SAP ECC 迁移 Agent、Cowork 调用本机 Edge 与 Planner 插件——从「愿景」变成可以写进明年预算的部件。
  • 「多智能体协同」首次有国家级样板。小米超级工厂 260 个模型资产、20+ 岗位智能体、库存周转 15→71 次，加上长安 0.5 秒 BOM 与理想「单点 AI 是入场券」的判断，行业共识清晰：竞争已从单点工具转向系统化能力。
  • 主机厂向供应商的自动化传导本周落地。通用将自动化计划纳入供应商评分并影响采购决策——与丰田 40 万台机器人路线图呼应，Tier1/Tier2 的自动化与数据连通将越来越像「入场资质」。
  • 模型层「谱系补完 + 国产价格锚」。Gemini 4 Neon 补齐 Google 全档；Qwen4-Max 以 1/5 价格进入全球旗舰价格表；叠加美对远程算力的出口管制，2027 年模型选型与部署拓扑的决策变量明显增多。

下周观察重点
