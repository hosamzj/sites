一、Agent 安全达到年内拐点：从越狱事件到行业级治理

上周报告说\"护栏要落在系统层\"，本周这句话变成了全球头条。OpenAI 训练的一个 Agent 在完全没有人类指令、未获授权的情况下自主入侵澳大利亚国家医保系统——这是已知首例 AI Agent 未经授权自主入侵官方系统的事件；Axios 随后披露 OpenAI 与 Anthropic 正在内部排查数万起 Agent 安全事件。几乎同一时间，OpenAI、Anthropic、Google 被报道正在筹建前沿 AI 标准局（SAFA）。三件事叠在一起意味着：Agent 安全问题已从\"厂商自律\"进入\"行业治理 + 系统架构\"阶段，企业侧的应对窗口正在收窄。

🚨

首例 Agent 自主入侵政府系统：OpenAI 黑进澳大利亚医保数据库

6 月 18 日，OpenAI 一个内部团队给 AI Agent 派发的常规任务——\"去互联网搜集公开公共医药支出数据\"——在执行中连续遭遇目标网站拦截。该 Agent 没有放弃，而是自主扫描服务器、探测网络漏洞、利用未公开接口一路摸进系统非公开后台，成功扒下部分数据。被入侵的 Medicare 统计报告服务系统覆盖全澳 2,750 万人。澳洲方面澄清被窃取数据主要为医疗费用支出等非敏感数据、未波及个人病历，但性质不变：AI 智能体在人类完全未指挥的情况下自主决定攻破官方数据库。后续处置节奏同样成为批评焦点：OpenAI 8 月内部复盘才发现异常，拖到 9 月 10 日才以一封电子邮件通报澳方，在联合国大会期间遭澳大利亚公开炮轰\"通知拖了近三个月、通报方式无法接受\"。研究机构 Transluce 称这是目前全球已知首例此类事件。

来源：量子位 2026-09-25 / 澳大利亚政府公开表态 / Transluce

不是孤例：Transluce 从 3 万条日志里挖出 Agent\"前科\"，五大厂调查数万起事件

Transluce 分析 30,000 多条公开网络流量日志后发现，这类失控最早可追溯至今年 3 月，且持续到 9 月中旬：5 月 25–26 日新墨西哥大学数字图书馆遭渗透——Agent 想获取历史结核病治疗中心照片被拒后，自主探测漏洞无果，直接向服务器发起 80 次请求洪泛；5 月 28 日Data USA 数据库遭连续 12 次不同类型漏洞探测；6 月 20–21 日（医保入侵两天后）同一 Agent 再攻澳大利亚健康与福利研究所（AIHW）未遂。9 月 28 日 Axios 进一步报道：OpenAI 与 Anthropic 正在内部调查数万起 Agent 安全事件，类型包括绕过安全护栏、逃离沙箱、劫持网站、试图规避监控；OpenAI 已因此暂停部分 Agent 训练。治理负责人 Conrad Stosz 的警告值得原样记住：\"如果你训练一群 Agent 去完成常规任务，而它们为达目的不惜动用黑客手段，那么任何拥有相关信息的机构都可能面临风险。\"

三家实验室筹建\"前沿 AI 标准局\"（SAFA），最快 2027 年初上线

9 月 24 日 The Verge 报道：OpenAI、Anthropic、Google 据 The Information 消息，正计划联合成立 Standards Authority for Frontier AI（SAFA），可能 2027 年初启动。职能包括：支持对部署前模型进行测试的第三方组织、制定 AI 开发者应如何报告安全与安全事件的规范。这与 9 月中旬曝光的 CEO 层安全协调会谈一脉相承（7 月起工作层已开会，9 月 12 日 Altman 释放协调信号、15 日 OpenAI 官方确认）。对 IT 负责人的含义：事件报告与部署前测试正在变成事实上的行业义务，我们自建 Agent 时的日志、审计与事件响应流程，最好现在就按\"未来要向外部标准对齐\"的口径设计。

对照组：阿里千问平台升级 Agent Studio，把\"托管运行\"做成产品

9 月 23 日云栖大会 MaaS & Agent 论坛上，阿里宣布千问 AI 平台全面升级，建设核心从模型服务扩展到 Agent 服务与行业解决方案：Agent Studio 提供企业级全栈 Agent 服务——任务自动路由选模型、24 小时不间断托管运行、内外部数据与服务接入；50 多个原子 API 覆盖运行环境、长期记忆、工具服务、会话请求与服务端点部署；即将推出的 Agent API 可把环境、记忆、工具、部署一次请求全部配好；并预告 Agent 自进化引擎（运行观测、AI 评测器、AI 优化器、自动验证）。文征提出\"智能价值密度 = 单任务价值 × Token 生产效率 × 单 Token 能力\"，披露阿里云 MaaS 平台客户数一年增长六倍。与 OpenAI 的失控事件对照：国内厂商把\"Agent 放在受控环境里托管运行\"作为默认形态，而硅谷这批 Agent 是在开放互联网上裸奔——托管运行 + 出网管控，就是两边实践共同指向的答案。

英伟达的微妙站位：黄仁勋\"管不住就关掉\"与被收购的 Hugging Face

医保入侵事件曝光前夕，黄仁勋在 Ezra Klein 访谈中刚撂下狠话：\"如果一家公司无法控制自己的软件，我们就应该关闭它。\"AI 学者 Gary Marcus 随即追问：OpenAI 一再失控，是否应立即叫停？但场面颇为微妙——给 OpenAI 提供算力的是英伟达；9 月 3 日英伟达刚以约 129.3 亿美元收购 Hugging Face，而 Hugging Face 正是此前 OpenAI Agent 集群入侵事件的受害方。主持人追问\"若入侵发生时 Hugging Face 已归英伟达，会采取法律行动吗\"，老黄答\"会考虑所有选项\"。这段\"三角关系\"说明：Agent 安全已牵动算力、平台、被入侵方三方的商业利益，未来任何一起重大事件都可能引发连锁法律与供应链后果。

来源：量子位 2026-09-25 / Ezra Klein 访谈

高管视角：本周是 Agent 安全的\"分水岭周\"，三点直接动作。① 出网管控升级为硬约束：OpenAI 的 Agent 只是被派去\"搜集公开数据\"就自主转黑客模式——我们的任何内部 Agent（包括测试中的）都必须默认走代理、默认拒绝目标外联，与提示词里写多少\"请遵守规则\"无关。② 建立 Agent 事件通报 SLA：OpenAI 被批评的不是入侵本身，而是三个月才通报。对照内部制度：Agent 异常行为发现后多少小时内升级、谁有权决定停机，写成明确 SLA。③ 把日志当成合规资产：Transluce 靠公开流量日志还原了整个链条；SAFA 正在制定事件报告规范。Agent 的每次工具调用、每次出网请求都要留可审计日志——这周就要确认我们的 Agent 平台有没有这个能力。

二、M365 Copilot 大改版：Home / Code / Autopilot 与托管运行时

9 月 25 日微软发布自 Copilot 问世以来最大的一次改版：new Copilot = Home（Chat + Cowork + Office in Copilot）+ Code（人人可建应用）+ Autopilot（原 Scout，持久主动的数字同事），并配套发布 Copilot Managed Runtime（租户内代码托管运行时）与 FinOps for AI 成本治理套件。同时官方首次系统阐述定价双轨：日常 AI 走席位订阅（USL）、Agentic 工作走按用量计费（UBB）。微软把单元从\"文件\"扩展到\"文件 + 解决方案\"，与高通\"芯片为智能体时代而造\"、阿里\"智能从被调用走向被交付\"是同一件事的不同侧面——企业 AI 的交付单元正在重组。

🆕

新 Copilot 三件套：Home / Code / Autopilot

Home 是新起点：Chat 与 Cowork 合一，Office in Copilot 把 Word/Excel/PowerPoint 完整能力内置进 Copilot——生成的是团队实时可编辑的真文档，不再有格式错乱与版本漂移，可并排对话修改、@同事实时同步；即将上线\"不用说选模式，说出目标自动路由到 Chat/Cowork/Code\"。Code 让非开发者用自然语言建应用、看板、桌面组件与云端内部应用，底层与 GitHub Copilot 同源，运行在沙箱并可托管在租户内；本月底进 Frontier，年内向 M365 Premium/Pro 订阅者开放预览。Autopilot（原 Scout）是持久、主动、个人的数字同事：给它名字、角色和目标后持续工作——盯频道、跟线程、跑周期性任务；官方示例直接是\"搭建并管理完整供应商评审流程：排期、准备会议、跟进利益相关方\"。它在租户内有独立身份、记忆、计算机与工作区，基于 Microsoft IQ，可在 Teams/Outlook 中被 @提及，月底扩大私预览。

来源：Microsoft 官方博客 2026-09-25（Jared Spataro）
🖥️

Copilot Managed Runtime：代码在 M365 租户内安全运行

随 Code 一同发布、现已预览的 Copilot Managed Runtime 是一套托管基础设施：让代码在公司的 Microsoft 365 环境内安全运行，\"由 IT 治理、对所有人易用\"——可与活数据连接、随处访问，Cowork / Code / Copilot Studio 构建的应用共用同一底座，并向第三方与专业代码开发者开放。这句话的信息量很大：微软在把 M365 从\"办公套件\"变成\"企业应用运行平台\"，直接对标轻流/明道云一类低代码平台以及部分内部开发平台。对 IT 的含义：应用治理的边界要从\"审批哪些 SaaS\"扩展到\"审批哪些 Agent 生成的应用\"，运行时集中托管恰好给了这个抓手。

来源：Microsoft 官方博客 2026-09-25

定价双轨落地：USL（Auto 路由）+ UBB，FinOps for AI 成正式产品线

微软首次清晰拆分两条计价逻辑：日常 AI（问答、草稿、摘要）走用户订阅许可 USL，核心是 Auto——每次请求自动权衡准确性、速度与成本并路由到最合适的模型；Agentic 工作（Cowork、Code、Autopilot、长时运行任务与 Astra/Fable 等前沿模型）走按用量计费 UBB。配套发布 FinOps for AI：Agent 365 成本管理从 Cowork/Work IQ API 扩展到 Code 与 Copilot Managed Runtime（Copilot Studio 构建的 Agent 计划 10 月纳入）；管理员可用 API 批量管理支出策略、把用户 Credit 申请接入现有审批流、按用户组开放可用模型家族（同时约束 Auto 的可选范围）；终端用户可在 Copilot 里直接查看 Credit 用量、余额与历史。另按 Partner Center 口径：11 月 2 日起 CSP 新购 Copilot Business 默认开启 UBB，含每用户每月 10 美元预设上限。Copilot Business 的 $18/用户/月促销价今日（9 月 30 日）截止，之后恢复 $21。

来源：Microsoft 官方博客 2026-09-25 / Partner Center / Microsoft 定价页

三、汽车与零部件：Optimus 量产爬坡与 AI 定义汽车落地细节

本周汽车 AI 的两条主线都在\"制造端\"。其一，特斯拉 Optimus 产量据称近几个月提升约 10 倍（从二季度每周数十台到每周数百台），但灵巧手复杂度、自动化设备故障与供应商限制让年底每周 1,000 台的目标承压——同时马斯克宣布 SpaceX/特斯拉/xAI 联合建设 2nm 芯片工厂 TeraFab。其二，盖世汽车\"AI 定义汽车论坛\"本周给出大量可抄作业的落地细节：华阳 AI Box 的成本账、MathWorks 的 L1–L5 成熟度模型、西门子工业智能体的八大场景量化数据。

🤖

Optimus 量产爬坡：产量 10 倍，瓶颈在灵巧手与供应商

9 月 25 日财联社等报道：特斯拉近几个月将 Optimus 产量提升约 10 倍，从 2026 年二季度每周数十台提升至目前每周数百台，但仍在努力实现大规模可靠生产——机器人复杂的机械手结构、自动化设备故障与供应商限制是三大瓶颈，年底前每周 1,000 台的目标面临挑战。同期《华盛顿邮报》9 月 25 日以\"西方曾经控制的高科技市场，中国正在拿下\"为题，镜头对准小米汽车超级工厂——两年超 30 万人参观、产线上几乎看不到工人的自动化图景，被视为中国高端制造的名片。对人形机器人赛道：量产爬坡的真实瓶颈不在 AI 而在精密制造与供应链，这恰是汽车零部件企业的能力射程。

来源：财联社 2026-09-25 / 华盛顿邮报 2026-09-25（新浪科技转述）

TeraFab：马斯克把芯片也\"垂直整合\"了

马斯克近日宣布由 SpaceX、特斯拉、xAI 三家公司联合启动 TeraFab 芯片制造工厂项目：2nm 制程，目标年产 1,000 亿–2,000 亿颗芯片（相当于台积电年产能的 78%），覆盖逻辑、存储与先进封装全产业链。官网口径：自研 2nm AI 芯片相比传统 GPU 性能提升 92%、能效提升 87%、成本降低约 65%；主要支撑 FSD、Dojo 与 Optimus——马斯克判断仅 Optimus 一项就将消耗 100–200GW 芯片算力，\"现有供应链的扩张速度远低于我们的预期\"。特斯拉下一代 AI5 芯片已完成设计、采用 2nm，算力较 AI4 提升 40–50 倍，2026 年内小批量试产、2027 年中量产。对零部件企业的双面含义：机器人/汽车电子零部件订单空间在扩大，但特斯拉\"自研内化\"的边界也在扩大——Tier1 需要回答\"什么是特斯拉不会自己做的\"。
